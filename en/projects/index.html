AssetForge

2026 In development

Game asset generator ready for Unity: from a text description (or an image) to a Humanoid FBX with textures, prefab and animations.

Why it exists

Making 3D characters for a small game is expensive and needs paid tools. The goal is to reach the same result with free tools and free quotas only.

Technical decisions

  • Clean Architecture in Python, with an AI provider router that switches services when a free quota runs out.
  • Headless Blender and MakeHuman generate fully rigged characters, plus a library of 45 free animations.
  • A Unity package imports everything on its own: Humanoid Avatar, URP materials, prefab and a locomotion Animator. 73 tests.

Technologies: Python, FastAPI, pytest, Unity, AI-assisted development

Copiloto de Trading

2026 In use, on a demo account

Decision-support system for trading on MetaTrader 5, in observation mode: it reads the chart, sizes the risk and explains, but never places an order.

Why it exists

It started from a request for "98% accuracy". The first thing it does is explain why that number does not exist, and what to measure instead.

Technical decisions

  • Never shows a confidence percentage: it shows "3 of 4 criteria aligned", checkable item by item on the chart.
  • Logs every trade in a journal, to measure whether there is a real edge.
  • Has 743 automated tests; the autonomous executor runs on a demo account only, reviewed weekly.

Technologies: Python, FastAPI, pytest, Docker, AI-assisted development

E-PLAY

2026 Android APK

App for the E-PLAY community: schedule matches, score on a leaderboard, read the Bible as a group and follow the live streams.

Technical decisions

  • React with Capacitor builds the Android APK from the same web code, with builds on GitHub Actions.
  • Supabase on the back end: Google sign-in, LGPD consent and a public profile with privacy controls.
  • Rule-based automatic moderation (block, warn, ban), an offline Bible with search, and a color-blind mode with 4 options.

Technologies: React, TypeScript, Capacitor, Supabase, PostgreSQL, Tailwind CSS, CI/CD, AI-assisted development

Mini n8n

2025 Open source

Technical decisions

  • React front end with React Flow: the flow is built by dragging nodes.
  • REST API in Node.js and Express that talks to the Telegram API, with a configurable delay between sends to avoid being blocked.

Technologies: React, React Flow, Tailwind CSS, Node.js, Express, REST APIs
